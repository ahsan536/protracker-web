FAQ

Clear answers before users launch the software.

Does the launch button open the actual app?

Yes. It hides this website shell and reveals the integrated ProTracker software inside the same page.

Will existing ProTracker data still work?

Yes. The implementation preserves the same localStorage and IndexedDB names used by the original tracker.

Does this require hosting or a backend?

No. This version is a static HTML website with a local image asset and the existing app embedded into it.

Can users return to the website after launching?

Yes. A small Website button inside the app returns to the marketing page without deleting or changing data.

Ready to enter the command center?

Launch ProTracker and start with onboarding, or go straight into the dashboard if your profile is already set up.
